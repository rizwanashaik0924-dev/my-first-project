# 🌤 Weather Dashboard

A simple weather dashboard that allows users to search for a city and view current weather information.

## Features

- Search weather by city
- Current temperature
- Humidity
- Weather description
- Weather icons
- Enter key support
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## How to Run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Add your OpenWeather API key to `script.js`.
4. Search for a city.
